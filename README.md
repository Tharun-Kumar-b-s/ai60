# AI60: Build Your First AI Project

Growth engine for the "Build Your First AI Project in 60 Minutes" workshop. Full README is written in Phase 11.

## Run locally
    npm install
    cp .env.example .env.local   # add DATABASE_URL (see DB_SETUP.md)
    npm run db:seed              # creates tables + demo data
    npm run dev                  # http://localhost:3000
